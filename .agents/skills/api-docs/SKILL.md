# API 接口文档模板（宿主无关）

> 版本：v1.0（2026-09-12）· 维护仓库：vibe-coding · 新项目从本目录复制，升级以本仓库为准。

目标：任何项目的接口文档都长一个样——读者扫一眼就知道怎么发出第一个请求。排版节奏对齐 uni-id-co 官方文档的阅读体验；响应信封（envelope）随项目自定，本模板不绑定任何一种。

## 1. 适用范围与组织

- 本技能只管「怎么写好接口文档」，不绑定文档工具：VitePress / 纯 Markdown / README / GitHub Wiki 直接照写；语雀 / Confluence / Notion 等富文本 wiki 保持同样的章节顺序与禁令，把行内代码、表格、代码块换成宿主等价物。
- 一套 API 文档 = **一页全局约定 + 每接口一节**。Base URL、鉴权方式、响应信封结构、统一错误规则只在全局约定写一次，接口节绝不重复。
- 接口多时按业务域分页（用户 / 存储 / 通知…），别把上百个接口塞进一页；同一文档内接口标题层级保持一致（由页面层级决定用 `###` 还是 `##`）。

## 2. 每个接口的固定结构（顺序固定，缺项注明而非删段）

````md
### 中文接口名

**接口名**：`register`

**接口形式**：`POST /v1/user/register`（需登录的加注；无请求体的加注「无请求体」）

**请求体**：

```json
{
  "username": "alice",
  "password": "secret123"
}
```

**参数说明**：四列表（参数名 / 类型 / 必填 / 说明），可选字段必填列写「否」或「视配置」。

**返回值**：嵌套字段平铺写 `data.token` / `data.user.id`，只写 data 内层。

**失败**：「状态码 × 触发场景」表，场景只有一两个时行内列举即可。

**注意**：边界与坑（幂等性、审计留痕、配置联动等）。
````

八段从上到下，各自职责：

1. **中文接口名**（标题）：读者语言，不是程序语言。
2. **接口名**：程序标识符（行内代码），供排查日志、代码对账。
3. **接口形式**：`` `METHOD /path` `` 行内代码，一眼可扫。路径版本前缀（`/v1` 等）按项目实际路由写，不要照抄模板示意。
4. **请求体**：独立 json 代码块。
5. **参数说明**：四列表。
6. **返回值**：注明成功时的 HTTP 状态；嵌套参数平铺。
7. **失败**：让读者拿着报错能对号入座。
8. **注意**：只写真实的坑，没坑就删掉整段——「请注意参数合法性」这类空话禁止出现。

## 3. 硬规则（违反任何一条 = 重写）

1. **接口形式与请求体分离**：接口形式是行内代码；请求体单独一块代码块。禁止裸代码块混写 HTTP 头与 JSON——混写块没有语法高亮，读者也不能直接复制当请求体用。
2. **代码块必须标 `json`，JSON 多行格式化**（每字段一行），禁止单行压缩——压缩块无法逐字段 review，改接口时 diff 不可读。
3. **请求体只列最小必填集**：可选字段不进示例，只进参数表——示例是读者照抄的起点，混入可选字段会误导必填判断。
4. **无请求体的接口不画代码块**：写明「无请求体」+ 鉴权方式与查询参数即可。
5. **返回值只写 data 内层**：信封（code/message 等外层字段）已在全局约定定义过一次，接口节再抄一遍必然与全局定义漂移。
6. **不写 SDK 调用形式**（项目暂无官方 SDK 时）：写清 HTTP 层，读者自己能封装。
7. **八段顺序不许换**：读者会形成肌肉记忆，乱序等于每页都要重新学习排版。

## 4. 完整示例（照此密度写）

````md
### 用户注册

**接口名**：`register`

**接口形式**：`POST /v1/user/register`（无需登录）

**请求体**：

```json
{
  "username": "alice",
  "password": "secret123",
  "captcha": "a7xk2"
}
```

**参数说明**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | string | 是 | 3-32 位字母或数字，全局唯一 |
| password | string | 是 | ≥ 8 位，建议含字母与数字 |
| captcha | string | 是 | 图形验证码票据，先调「获取验证码」接口取得 |

**返回值**（HTTP 200）：`data.token`（会话令牌，后续请求携带）、`data.user.id`（新用户 ID）。

**失败**：

| HTTP | 触发场景 |
|------|----------|
| 400 | 用户名已被占用 / 验证码错误或过期 |
| 429 | 触发注册频控 |

**注意**：用户名重复返回 400 而非自动改名；注册成功即建立会话，无需再调登录接口。
````
